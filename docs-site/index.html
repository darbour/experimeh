Features

🚩 Feature Flags

Real-time feature flag evaluation with targeting rules and gradual rollouts

🧪 A/B Testing

Traditional two-variant experiments with statistical significance testing

📊 Factorial Design

Test multiple factors simultaneously and detect interactions between variables

🔄 Switchback Experiments

Temporal switching to mitigate network interference in marketplace experiments

📈 Stepped Wedge

Cluster-randomized trials with sequential rollout to all clusters

⚡ High Performance

Deterministic assignment with caching, <10ms latency for assignments

📡 Scalable

Event-driven architecture with Kafka for high-throughput data pipelines

🔒 Type Safe

Written in TypeScript with full type coverage and comprehensive validation

Getting Started

Installation

npm install experimeh

Quick Example

import { createClient } from 'experimeh';

// Create a client instance
const client = createClient({
  apiUrl: 'https://experiments.example.com',
  apiKey: 'your-api-key',
});

await client.initialize();

// Get assignment for a user
const assignment = await client.getAssignment('exp-123', 'user-456');
console.log('Assigned variant:', assignment.variantId);

// Track exposure
await client.trackExposure('exp-123', 'user-456', assignment.variantId);

// Track metric
await client.trackMetric('exp-123', 'user-456', 'conversion', 1);

// Shutdown gracefully
await client.shutdown();

Experiment Types

Simple A/B Test

Compare two variants to determine which performs better

const experiment = {
  type: 'ab',
  variants: ['control', 'treatment'],
  allocation: [0.5, 0.5]
};

Factorial Design

Test multiple factors simultaneously

const experiment = {
  type: 'factorial',
  factors: [
    { name: 'button_color', levels: ['blue', 'green'] },
    { name: 'button_text', levels: ['Buy Now', 'Add to Cart'] }
  ]
};

Switchback

Temporal switching to reduce network effects

const experiment = {
  type: 'switchback',
  switchDuration: 3600, // 1 hour
  variants: ['control', 'treatment']
};

Stepped Wedge

Gradual rollout across clusters over time

const experiment = {
  type: 'stepped_wedge',
  clusters: ['region_1', 'region_2', 'region_3'],
  stepDuration: 86400, // 1 day
  sequence: [0, 1, 2] // rollout order
};
